## What is sleepKIT?

Building a sleep-monitoring model involves recordings and labels, signal processing, a training setup and a way to assess the result. sleepKIT brings those pieces into a configurable Python workflow for wearable and edge applications.

Start with an included task, run it from the command line or adapt the workflow through the Python API. The task and guide pages explain the options in detail, including how to prepare a model for integration on Ambiq devices.

## Installation

In a Python 3.12 project, add sleepKIT and check that the command line tool is available:

```bash
uv init --python 3.12 my-sleep-project
cd my-sleep-project
uv add sleepkit
uv run sleepkit --help
```

The [quickstart](/sleepkit/quickstart/) covers `pip` and source-checkout installation, configuration and your first workflow.

Code and Ambiq-authored documentation use BSD-3-Clause, except separately licensed material. Model weights and datasets have [their own terms](/sleepkit/model-licensing-policy/).
